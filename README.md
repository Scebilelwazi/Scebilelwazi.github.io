# Nolwazi Mahlambi – Virtual CV / Portfolio

## Overview
This is my personal portfolio website built as part of the IT Developments module. It serves as my Virtual CV and showcases my skills, projects, certifications, and professional background in cybersecurity.

## Technologies Used
- HTML5
- CSS3 (via Dimension template by HTML5 UP)
- JavaScript
- Hosted on GitHub Pages

## Sections
- **About Me** – Personal introduction and career aspirations
- **Projects** – Showcase of my academic and personal projects
- **Resume** – Detailed CV summary with downloadable PDF
- **Contact** – LinkedIn, GitHub, and email links

## Setup Instructions
1. Clone this repository
2. Open `index.html` in your browser
3. Or visit the live site at: https://Scbelilewazi.github.io
